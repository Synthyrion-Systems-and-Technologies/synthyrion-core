# Features, with honest status 

Each row is a feature Synthyrion Core L5 sets out to have, and where it stands. The table below is generated from the project’s own equivalence table; it is not edited by hand, so it cannot drift from the truth. 

**Status.** Synthyrion Core L5 is a capability-based microkernel written in Rust. Its primary target is x86-64. AArch32, AArch64 and RISC-V 64 ports run in emulation (QEMU) only. It is under active development. Its feature status is published on this site, with the strength of each piece of evidence (tested / bounded / panic-free / functionally proven; host, virtual machine or hardware). **It has no safety, security or government certification. There is no whole-kernel functional-correctness proof. It is not FIPS 140-3 validated.**  

**How to read the status.** Done the feature exists and a test or proof row checks it; the strength of that evidence (host, virtual machine or hardware; tested, bounded, panic-free or functionally proven) is in the row. Done (blue) submitted as complete with the stated limit. In progress part exists, and the gap is named. Planned not started. “Different design” means the guarantee is provided by a mechanism of Synthyrion’s own, described in the row. 

A Done row is not a functional-correctness proof. The strength of the checking behind each row is on the [assurance goals page].
