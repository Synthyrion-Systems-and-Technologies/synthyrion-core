# Platforms, and what ran where 

A virtual machine is not hardware. Every result on this page is labelled by where it ran. 

## §1The labels  Evidence labels        

| Label | Meaning |
|---|---|
| SILICON | Ran on a real machine, with the privileged boot path. |
| USER-SPACE ON SILICON | Real hardware ran the kernel’s logic as an ordinary program. This is not the privileged MMU, interrupt-controller or exception path. |
| VM | Ran under an emulator or hypervisor (QEMU, Windows Hypervisor Platform). It is emulation evidence only. |
| NO SOURCE | Nothing exists yet. |
